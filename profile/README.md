# PT Ananta Artha Sejahtera

Technology company based in Kendal, Jawa Tengah, Indonesia.

We build **[Akademi](https://akademi.ink)** — an academic writing workspace for Indonesian university students: makalah & skripsi in a Word-like A4 canvas driven by campus formatting guidelines (pedoman), with citations, review-first AI revision, and honest PDF/DOCX export.
